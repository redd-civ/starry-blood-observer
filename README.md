# Звёздная Кровь — Энциклопедия и Наблюдатель

Проект для систематизации правил «Звёздной Крови» и последующего создания инструмента Наблюдателя для мастера НРИ.

## Структура

- `docs/` — сайт энциклопедии (GitHub Pages)
- `docs/encyclopedia/` — тематические статьи
- `docs/data/` — структурированные данные для будущего инструмента

## Принципы достоверности

Каждое правило получает отметку: подтверждено источником, вывод, не установлено или правило мастера. Числа и ограничения не считаются общими правилами, если источник приводит только частный пример.

Полный исходный PDF не включается в публичный репозиторий. В энциклопедии размещаются собственные краткие пересказы и ссылки на страницы источника.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → `main` → `/docs`.
