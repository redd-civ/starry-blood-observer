Генератор наград Наблюдателя

Рабочая версия инструмента мастера: после выполнения задания выбирается категория, Наблюдатель предлагает три варианта, игрок выбирает один.

Важно о правилах. Подтверждено: выбор одной из девяти категорий, три случайных предложения и выбор одного варианта. Вероятности категорий, распределение качества и правило повторов в источниках не установлены. Поэтому генератор не придумывает эти параметры: режим повторов задаёт мастер, качество берётся из записи награды.

Пулы частично наполнены вариантами из трёх наградных панелей: Руна-Предмет (золото), Руна-Существо (серебро), Руна-Домен (серебро). Это примеры, а не полный каталог. Остальные категории пока не заполнены именованными вариантами. Открыть каталог наград с источниками · Справка о рунном ремесле.

1. Результат задания

Поля Славы и Монет только фиксируют уже определённую награду за задание. Генератор не вычисляет их по неподтверждённой формуле.

2. Выбор категории и параметры генерации

Выбор категории — ручной. Для заданий о Червях Игг-эффекты должны встречаться чаще, для обычных — значительно реже. Точные коэффициенты не установлены: мастер задаёт их ниже. Пустое поле означает нейтральный вес 1:1, а не книжную вероятность.
